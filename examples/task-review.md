# Example review record

Blank evidence template for the fictional task brief. No checks have been executed or marked as passed in this example.

## Scope review

| Review item | Evidence to record |
| --- | --- |
| Changed files | Exact diff or commit |
| Requirement coverage | How each acceptance criterion is addressed |
| Scope boundaries | Any change outside the agreed task and its reason |
| API contract | Public fields, error responses, and validation |

## Check record

| Scenario | Example status | Evidence required before acceptance |
| --- | --- | --- |
| Known item | Not executed | Exact command and observed response |
| Unknown item | Not executed | Not-found response and browser behavior |
| Invalid identifier | Not executed | Validation response |
| Restricted fields | Not executed | Response assertion and UI inspection |
| Existing browsing | Not executed | Regression-check output |

## Human decision

Record acceptance, requested revisions, or deferral only after reviewing the actual change and evidence. Include unresolved concerns and who will handle them.
